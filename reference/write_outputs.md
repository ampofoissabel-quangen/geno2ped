# Write geno2ped outputs to disk

Write geno2ped outputs to disk

## Usage

``` r
write_outputs(res, outdir = "geno2ped_results", prefix = NULL)
```

## Arguments

- res:

  Result from
  [`build_pedigree()`](https://ampofoissabel-quangen.github.io/geno2ped/reference/build_pedigree.md)

- outdir:

  Output directory

- prefix:

  Optional file prefix

## Value

Invisibly returns a character vector of written file paths
